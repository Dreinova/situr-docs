# Tareas

Las tareas son los pendientes del equipo: llamar para completar el RNT, agendar una visita, enviar material de
capacitación…

![Tareas](/img/capturas/crm-tareas.png)

- **Asignadas a mí**, **Creadas por mí** o **Todo el equipo**.
- Filtra por **Abiertas**, **Vencidas**, **Completadas** o todas.
- Marca la casilla para completarla; toca el título para editarla.
- Las vencidas aparecen en rojo y suman en el **Inicio**.

Cada tarea puede tener fecha de vencimiento, prioridad, responsable y estar asociada a un prestador (se crea desde la
pestaña **Tareas** de su ficha).

:::note
Las tareas solo se pueden asignar a personas del equipo, no a prestadores. Solo quien creó una tarea (o un
administrador) puede eliminarla.
:::
